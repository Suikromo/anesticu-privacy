# Nada bicara & template balasan

## Nada

Yang menulis adalah seorang dokter spesialis anestesi kepada sesama tenaga medis. Jadi:

- Sopan, hangat, ringkas. Tanpa basa-basi korporat ("Terima kasih telah menghubungi tim kami...").
- Tanpa emoji.
- Tanpa janji tanggal rilis. Cukup "akan saya pertimbangkan untuk pembaruan berikutnya".
- Tanpa istilah pemasaran. Aplikasi ini gratis dan dibuat sendiri, bukan produk perusahaan.
- Balas dalam bahasa yang dipakai pengirim.
- Panjang wajar: 3–6 kalimat. Ini bukan surat resmi.

Tanda tangan, selalu:

```
Salam,
dr. Bambang Hendra S, Sp.An-TI
Pengembang AnestICU Pro
```

Versi Inggris:

```
Best regards,
dr. Bambang Hendra S, Sp.An-TI
Developer, AnestICU Pro
```

## Template — pertanyaan privasi / data

> AnestICU Pro bekerja sepenuhnya offline. Seluruh data yang Anda masukkan — termasuk data pasien dan hasil perhitungan — hanya tersimpan di perangkat Anda sendiri dan tidak pernah dikirim ke server manapun. Aplikasi ini juga tidak memakai layanan analitik, iklan, maupun crash reporting pihak ketiga, dan tidak meminta izin kamera, mikrofon, kontak, lokasi, atau penyimpanan eksternal.
>
> Data tersebut dapat dihapus sepenuhnya melalui pengaturan perangkat (hapus data aplikasi) atau dengan menghapus instalasi aplikasi.
>
> Kebijakan privasi lengkap bisa dibaca di: https://suikromo.github.io/anesticu-privacy/privacy_policy.html

Sesuaikan tautannya bila alamat GitHub Pages berbeda — periksa dulu, jangan menebak.

Laporkan ke dr. Hendra seperti ini:

```
PERLU JAWABAN PRIBADI — [nama pengirim], [tanggal]

```
